## ✨ Что делает программа

Я сделал эту программу для себя и буду рад, если она пригодится кому-то ещё. 💜

Pen Overlay показывает PNG-картинку стилуса (*скин*) в том месте, где находится перо графического планшета, и поворачивает её в сторону наклона пера. Удобно для записи экрана, стримов и уроков: зрители видят, *где перо* и *как его держат*.

- 🪟 **Оверлей, сквозь который можно кликать.** Картинка рисуется в прозрачном окне поверх всех окон, которое не перехватывает фокус и клики.
- 🎨 **Скины.** Добавляйте сколько угодно картинок стилуса и переключайте их в рисованном окне выбора.
- 🧭 **Калибровка.** Убирает смещение между картинкой и настоящим кончиком пера, если оно есть.
- 🫥 **Автоскрытие.** Стилус появляется, когда перо работает, и пропадает через 3 секунды без данных пера.
- 🔔 **Значок в трее.** `Settings`, `Reload` и `Exit` под рукой.

## ⚠️ Как сделать скин: кончик стилуса в ЛЕВОМ ВЕРХНЕМ углу

> ### 🔴 Кончик пера должен находиться в **левом верхнем** углу картинки, а корпус уходить к **правому нижнему**.
>
> Программа поворачивает картинку вокруг её кончика и ищет его сама: это **непрозрачный пиксель, ближайший к левому верхнему углу** изображения. Если кончик в другом месте, скин будет вращаться вокруг неверной точки и не попадёт на настоящий кончик пера.

**Чек-лист хорошего скина**

- [x] **PNG с прозрачным фоном** (пустые поля обрезаются автоматически).
- [x] **Кончик в левом верхнем углу**, корпус идёт по диагонали к правому нижнему (45°).
- [x] **Рекомендуемый размер: квадрат 520 × 520 px** (стилус идёт из угла в угол). Подойдёт любой размер, но см. примечание ниже.
- [x] Большие картинки уменьшаются так, чтобы длинная сторона была 260 px (`SPRITE_LENGTH_PX`). Маленькие картинки **не увеличиваются**: если файл меньше 260 px, скин показывается в своём размере.
- [x] Не оставляйте в левом верхнем углу лишние пиксели, тени и свечение: их примут за кончик.

> 💡 **Почему 520 × 520?** На экране стилус имеет длину 260 px, а 520 px ровно вдвое больше: картинка уменьшается без потерь и остаётся чёткой, в том числе на экранах с высоким DPI или с `--scale 1.5`. Если собираетесь использовать `--size 400` и больше, рисуйте скин не меньше этого размера, потому что программа картинки не увеличивает. Всё, что больше ~1000 px, лишь тратит память и заметной пользы не даёт.
>
> Пустые прозрачные поля обрезаются, поэтому важен размер самого стилуса, а не холста.

**Если ваш рисунок устроен иначе**, перерисовывать его не обязательно. В блоке настроек в начале `pen_overlay.pyw` можно изменить:

| Настройка | Смысл |
|---|---|
| `TIP_POINT = (x, y)` | положение кончика на *исходной* картинке вместо автоопределения |
| `BODY_DIRECTION_DEG` | куда направлена задняя часть стилуса, по часовой стрелке от «вправо» (`45` = вправо-вниз) |

## 🚀 Установка

1. Установите [Python 3.8+](https://www.python.org/downloads/) (отметьте *Add Python to PATH*).
2. Установите Pillow:
   ```bash
   pip install pillow
   ```
3. Скачайте проект и держите эти файлы вместе:
   ```
   pen_overlay.pyw
   skin_window.py
   stylus.png          ← скин по умолчанию (необязательно, без него будет встроенная заглушка)
   banner.png          ← значок в трее, 400×400 (необязательно)
   ui/                 ← графика и шрифт окна скинов
   skins/              ← ваши скины (создаётся сама)
   ```
4. Дважды щёлкните по `pen_overlay.pyw` (или запустите `python pen_overlay.pyw`).

### Параметры командной строки

```bash
python pen_overlay.pyw                # скин, выбранный в Settings
python pen_overlay.pyw my.png         # конкретная картинка
python pen_overlay.pyw --size 400     # длина на экране в пикселях (по умолчанию 260)
python pen_overlay.pyw --scale 1.2    # дополнительный множитель размера
python pen_overlay.pyw --no-stretch   # не менять длину стилуса от наклона
python pen_overlay.pyw --debug        # печатать данные пера и писать pen_overlay_log.txt
```

## 🎛️ Как пользоваться

### Горячие клавиши (работают из любого окна)

| Клавиши | Действие |
|---|---|
| `Ctrl` + `Alt` + `Q` | Выход |
| `Ctrl` + `Alt` + `1` | Калибровка: поставьте перо в **левый верхний** угол экрана и нажмите |
| `Ctrl` + `Alt` + `2` | Калибровка: поставьте перо в **правый нижний** угол экрана и нажмите |
| `Ctrl` + `Alt` + `0` | Сбросить калибровку |
| `Ctrl` + `Alt` + `T` | Тест вращения (стилус крутится сам) |

Калибровка нужна, только если картинка смещена относительно настоящего кончика пера. Она сохраняется сама.

### Значок в трее

Щёлкните по значку в области уведомлений: **Settings** (окно скинов), **Reload** (перезапуск программы), **Exit** (выход).

### Окно скинов

| Действие | Как |
|---|---|
| Добавить скин | перетащите один или несколько **PNG** в окно |
| Выбрать скин | щёлкните по нему (применяется сразу и запоминается) |
| Удалить скин | выберите его и нажмите **Delete** (скин по умолчанию удалить нельзя) |
| Прокрутка | колесо мыши, `↑` `↓`, `PgUp` `PgDn`, `Home` `End` |
| Окно | таскайте за рамку; кнопки в правом верхнем углу сворачивают, разворачивают и закрывают (`Esc` тоже закрывает) |

Подпись под скином это имя файла без `.png`, поэтому называйте файлы красиво. Каждому скину достаётся случайная рисованная рамка.

> Названия рисуются шрифтом *PenHand*, в котором есть только латиница и цифры. Остальные символы (например, кириллица) рисуются системным шрифтом.

## 🗂️ Структура проекта

```
pen_overlay.pyw        основная программа: ввод пера, оверлей, трей, скины
skin_window.py         окно выбора скинов (рисованное, без системной рамки)
build_ui_assets.py     необязательно: пересобирает ui/ из макетов в src_png/
ui/                    рамка окна, состояния кнопок, обводки ячеек, layout.json, PenHand.ttf
src_png/               исходные макеты, из которых нарезана графика ui/
skins/                 ваши скины стилуса (PNG)
stylus.png             скин по умолчанию
banner.png             значок в трее
pen_overlay_settings.json   выбранный скин (создаётся сам)
pen_overlay_calib.json      калибровка (создаётся сама)
```

**Перерисовать окно.** Замените картинки в `src_png/` (сохранив цветные зоны `layout.png`) и запустите `python build_ui_assets.py` (нужны `numpy` и `scipy`, только для этого шага).

## 🔧 Тонкая настройка

Все настройки в начале `pen_overlay.pyw`, например:

| Настройка | По умолчанию | Смысл |
|---|---|---|
| `SPRITE_LENGTH_PX` | `260` | длина стилуса на экране |
| `SMOOTHING_TAU` | `0.07` | сглаживание наклона, секунды (`0` = без сглаживания) |
| `HIDE_AFTER_SEC` | `3.0` | через сколько секунд без данных пера скрывать (`0` = всегда виден) |
| `INVERT_X` / `INVERT_Y` | `False` | зеркало по горизонтали / вертикали |
| `STRETCH_BY_TILT` | `False` | укорачивать стилус, когда перо стоит вертикально |

## ❓ Если что-то не так

- **Ничего не появляется.** Сначала поводите пером над планшетом. Запустите с `--debug` и посмотрите `pen_overlay_log.txt`.
- **Картинка сидит рядом с кончиком пера.** Проверьте скин (кончик в **левом верхнем** углу), затем попробуйте калибровку (`Ctrl+Alt+1` / `Ctrl+Alt+2`).
- **Стилус вращается вокруг не той точки.** В левом верхнем углу PNG есть лишние пиксели. Уберите их или задайте `TIP_POINT`.
- **Не в ту сторону.** Задайте `BODY_DIRECTION_DEG` или отразите картинку.
